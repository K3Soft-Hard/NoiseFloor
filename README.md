# NoiseFloor
New type of noise removal tool for astrophotography.

# Release tags
- U = UI (the app that displays)
- E = Engine (backend for math)

Both are required and every drop is marked with version use the newest version you can find of UI and Engine, they sometimes are in different Releases (for ex. find U1_0 and release E_9, when there is U+E_10 then use that).
